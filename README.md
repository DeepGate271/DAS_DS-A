# 🍳 Página Colaborativa de Receitas

## 📖 Descrição do Projeto

O projeto **Página Colaborativa de Receitas** é um espaço digital criado para reunir e partilhar diversas receitas culinárias escolhidas e documentadas pelos membros da equipa. 

Mais do que um simples livro de receitas, este repositório tem um propósito educacional prático: **aplicar e consolidar boas práticas de versionamento de código e trabalho colaborativo utilizando Git e GitHub.** Durante o desenvolvimento, a equipa utiliza fluxos de trabalho reais, incluindo a gestão de *branches*, resolução de conflitos, abertura de *issues* e revisões de código através de *Pull Requests*. As receitas são desenvolvidas e formatadas utilizando as linguagens Markdown e HTML.

## 🚀 Como Executar e Visualizar o Projeto

Como o projeto é construído com base em ficheiros estáticos (Markdown e HTML), não é necessária a instalação de frameworks complexas ou bases de dados. Para aceder e visualizar as receitas localmente, segue estes passos:

### Pré-requisitos
- Ter o [Git](https://git-scm.com/) instalado na tua máquina.
- Um navegador web atualizado (Chrome, Firefox, Edge, etc.).

### Passos para execução local
1. **Clona o repositório** para a tua máquina local abrindo o terminal e executando o comando:
   ```bash
   git clone [https://github.com/teu-usuario/nome-do-repositorio.git](https://github.com/teu-usuario/nome-do-repositorio.git)
Acede à pasta do projeto:

Bash
cd nome-do-repositorio
Visualização dos Ficheiros:

Receitas em Markdown (.md): Podem ser lidas diretamente na interface do GitHub, ou através de qualquer editor de texto/código (como o VS Code) que suporte pré-visualização de Markdown.

Receitas em HTML (.html): Basta navegares até à pasta do projeto no teu explorador de ficheiros e dares um duplo clique no ficheiro principal (ex: index.html ou o ficheiro da receita específica) para o abrir no teu navegador web.
